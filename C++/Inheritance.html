syntax information and rules
Features
1) Base class: The class that is providing the members to be inherited
2) Derived class: The class that is inheriting the properties of the Base class
Properties:
1) The derived class is able to use the identified members of the Base class
2) Members obtained from the base class does not need to be defined from the derived class
3) A base class can have multiple derived classes
4) A derived class can inherit properties from multiple base classes
5) Derived class can only inherit public and protected properties of the base class
6) Allows one class to use properties of another class without the need to dupluicate the code for each class
7) Easier to maintain and make changes as changes to the base class will be reflected to all connected derived classes
8) When creating derived classes, the constructor of the derived must contain the members of the inherited base class in the constructor
9) Inherited memebers does not need to be redefined in the derived class
10) Derived classes can have functions that are not in the base class

info and Rules
What is diamond problem?
When two base classes inherit from a common base class creating a copy of the members into those two sub base classes
When a derived class inherits from the two sub base classes it will create a ambiguity error
__ The derived class inherits two copies of the common base class memebers, one from each sub base class
Info:
1) virtual public is placed onto the sub base classes where the derived class will inherit
2)virtual public will check at compile to ensure that a copy of the current constructor does not already exist in the derived class
