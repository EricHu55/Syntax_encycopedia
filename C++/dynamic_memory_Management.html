code breakdown
create new item: d_type* name = new d_type(element)
delete heap variable: delete heap_var
d_type : datatype of the value assigned to the variable
* name : This creates a pointer and name is the name of the pointer
element : the element being assigned to the pointer
note:
1) heap values can only be created with pointers
2) heap values are not assigned to a variable but memory is allocated to it as it is being executed on runtime
____That is why heap values are assigned to pointers and the pointer is not pointed to a known existing variable
3) Heap variables acts similar to normal variables with the exception that heap variables do not get deleted automatically after the execution of a function
