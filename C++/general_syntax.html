cin.ignore function

code breakdown
cin.ignore(counter,delimitier)
cin.ignore : cin method to ignore input of the carrot for the next input
counter : this is an integer that represents the number of characters to skip
delimiter : This is the value to stop skipping (only applies to the first character it encounters that matches
note:
1) cin.ignore does not provide a return, so it must be entered the line above of the cin line
2) the counter for cin.ignore is inclusive, so it will skip all characters up to the counter value
3) The delimiter will stop when the first character it encounters matches the delimiter
4) The delimiter takes precident over the counter, so if the character entered matches the delimiter, the delimiter cin.ignore function will stop at that character even though it is below the counter value
