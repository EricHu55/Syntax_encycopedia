class static members

code breakdown
note:
static members are when it can affect all created instances(objects) but only one instance would be created. Usually a copy of all the members of the class is created for each created instance. However for a static member, it can be called in the constructor, but no matter how many instances are created only one instance of the static member will exist
Rules:
1) static members cannot access information from non-static members
2) only static functions can access the static member
3) static members are only initialized in the class to alert the compiler of it's existance, but it is not defined in the class
____The static member is defined outside of the class but before the main function
____static memeber is defined in the driver file
____purpose is to act like a global variable being called to store changes caused from loops
